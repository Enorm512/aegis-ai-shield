# Source provenance

2026-10-25: original AI-assisted implementation authored for this task from user functional requirements and Android/Java API contracts. Root reviewed all supplied project files and both reports. Implementation agents received functional specifications; no Rethink, Hypatia, App Manager, TrackerControl, NetGuard or MobSF source was downloaded or copied into this release.

| Component | Origin | Review status |
|---|---|---|
| core URL/message/hash rules | New implementation and synthetic tests | Automated tests plus local review; independent human review pending |
| archive guard | New Java ZIP preflight | Adversarial synthetic fixtures; not formal parser audit |
| app | New Kotlin UI/platform adapters | Build and device status in TEST_RESULTS.md |
| reference reports | User-supplied ZIP, preserved | Historical claims not independently reproduced here |
| Gradle wrapper if present | Official Gradle distribution | Third-party build tooling, retain standard notices |

Not a legally certified clean-room process: AI agents are not independent human reviewers, and original specification provenance is user-supplied. No blanket claim that independent development eliminates third-party licensing. The project owner licensed the original source under the Apache License 2.0 on 2026-11-07 (LICENSE, NOTICE); third-party dependencies retain their own terms. No production threat database or proprietary assets are bundled. The app does bundle the experimental text-classifier weights (`ml/model/message_model.txt`, trained here from a developer-written, AI-assisted corpus in `ml/data/`; no third-party datasets or pretrained models; two CC BY 4.0 public SMS datasets are stored in `ml/external/` for experiments only and are not in the shipped model, see ml/external/README.md for attribution).

## Stage 5
Manifest parser, capability rules, look-alike detector, firewall policy and detectors are original. The binary-XML layout follows Android's public AOSP documentation of the chunk format (read from memory of the specification; no third-party parser code was copied). Brand names and official domains are factual lists written by the developer; they have not been reviewed by the brand owners.

## Stage 6
No third-party source added. `tools/check_release_apk.py` and `tools/check_android_api.py` are original; the latter reads the SDK's api-versions.xml and `javap` output.

## Visual identity
All icon and logo geometry is original, generated by tools/gen_icons.py from circles, rounded rectangles and hand-placed curves; no Material Icons, Feather or other third-party path data is included (an earlier idea to use remembered Material path strings was dropped).
