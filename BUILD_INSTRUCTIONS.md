# Build and installation

## Host tests (no Android SDK or external dependencies)
Install a full JDK17 or use a Java17 runtime containing jdk.compiler. From the project root run `bash core/run-tests.sh`. JAVA_HOME is honored when set; otherwise java from PATH is used. Python3 runs `python3 tools/check_privacy.py`. `core/demo.sh url|message` reads stdin and compiles the same engine used by the app.

For a full JDK and installed Gradle8.11.1, isolated Gradle core tests can run with `gradle -p core -c standalone.settings.gradle.kts check --offline`. The direct runner is the verified path in this session; Gradle's compiler capability detection failed on the host's incomplete JDK layout.

## Android Studio
1. Install Android Studio and a full JDK17. Open the project root containing settings.gradle.kts.
2. Review and accept Android SDK licence terms yourself. Install Android SDK Platform 36, Build Tools 36.0.0 and Platform Tools through SDK Manager. Do not commit local.properties.
3. Allow Gradle to resolve Google Maven/Maven Central/plugin dependencies. Sync. Versions: AGP8.9.2, Gradle8.11.1, Kotlin/Compose compiler2.1.20.
4. Run `./gradlew :core:check :app:lintDebug :app:assembleDebug :app:assembleDebugAndroidTest` (Windows: gradlew.bat). Test builds can download test dependencies.
5. Run `./gradlew :app:connectedDebugAndroidTest` with an Android8.0+ device/emulator; use API 36 initially and also test API 26/28. Emulator/device tests have NOT run in this session.
6. Only after a successful build, the debug APK should appear at app/build/outputs/apk/debug/app-debug.apk. Install that artifact using Android Studio Run or `adb install -r app/build/outputs/apk/debug/app-debug.apk` on your test device. This package itself contains no APK.

Application ID is com.aegis.aishield for release and com.aegis.aishield.debug for debug builds (so a debug build can never replace or be mistaken for a release install); versionCode 17 / 0.8.0-rc11. A previous prototype signed with a different development key may require uninstalling it first; do not do so without reviewing data-loss implications. Debug signing is generated by the local Android build tools, not a production release identity.

Review its actions and dependencies before enabling it. ## Verified local build (Windows)
With ANDROID_HOME pointing at an SDK with platform 36 and build-tools 36.0.0, and local.properties holding sdk.dir, the build succeeded from a normal user terminal. Gradle failed with 'Unable to establish loopback connection' inside the agent sandbox, so build from your own terminal.

## Release builds (Stage 6)
Debug: `gradlew :app:assembleDebug`. Release: create `keystore.properties` in the project root (never commit it) with `storeFile`, `storePassword`, `keyAlias`, `keyPassword`, then `gradlew :app:assembleRelease`; without the file the output is `app-release-unsigned.apk`. Gate checks: `python tools/check_release_apk.py app/build/outputs/apk/release/app-release.apk <sdk>/build-tools/36.0.0`, `python tools/check_android_api.py <core classes> <sdk>/platforms/android-36/data/api-versions.xml 26`, `python tools/check_privacy.py`. Run Gradle from your own terminal if it fails with "Unable to establish loopback connection" inside a sandboxed shell. When dependencies change, regenerate checksums with `gradlew --write-verification-metadata sha256 <tasks>` and review the diff of gradle/verification-metadata.xml.
The delivered `AegisAIShield-0.8.0-rc11-release-TEST-SIGNED.apk` is signed with a THROWAWAY key and exists only for testing; it must not be distributed or used for updates.

## Agent SDK and sample agent
`gradlew :agent-sdk:check` runs the SDK host tests. `gradlew :sample-agent:assembleDebug` builds the demo agent (`com.aegis.sampleagent`, debug-signed, no permissions). Root `build.gradle.kts` does not declare `com.android.library` separately: the library plugin comes from the same, already verified Android Gradle Plugin jar, so `gradle/verification-metadata.xml` did not need new entries. The sample agent pins the app's lifecycle versions and has no test variants for the same reason.
