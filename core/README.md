# Aegis offline analysis core

Original dependency-free Java source. The public API is callable from Kotlin. No analyzer performs DNS lookups, HTTP requests, or uploads.

- `UrlAnalyzer.analyze(String)`: at most 8,192 UTF-16 code units; HTTP(S), strict IDN conversion, canonical IP literals, authority/user-info parsing, Unicode display evidence, and a deliberately small brand-domain heuristic. Unknown schemes, malformed or unsupported formats return `INSUFFICIENT_EVIDENCE`. Scheme-less inputs assume HTTPS. ASCII host evidence shows the destination. Mixed Latin/Cyrillic or Latin/Greek labels are suspicious. Known shortening hosts yield insufficient evidence because the destination remains unresolved; no redirects are fetched. Controls are rejected before surrounding ordinary spaces are trimmed. HTTP, IP addressing, and internationalized spelling are not malicious by themselves.
- `ScamAnalyzer.analyze(String)`: at most 100,000 UTF-16 code units; English/Norwegian patterns and up to 12 embedded HTTP(S) links. Requests for secrets, unusual payments, and prize fees are combined with pressure indicators. Unparsed or unresolved embedded links and capped link coverage yield insufficient evidence unless stronger indicators are present. This is heuristic text analysis, not an AI authorship detector. Quotes, negations, and context can cause false positives; paraphrases and other languages can evade detection.
- `HashScanner.sha256(InputStream,long)`: bounded streaming SHA-256; caller closes the stream. Reads one byte beyond the limit to establish overflow and throws `IOException` instead of returning a partial digest. A hash alone says nothing about maliciousness.
- `HashScanner.match(String,HashIntelligence)`: optional provider boundary for exact matches in independently maintained, trusted malware hash intelligence. No provider or intelligence database ships in this module. Only an exact provider match uses `CONFIRMED_MALICIOUS`; a miss is not proof of safety.

The official-domain list is intentionally incomplete and is not a public-suffix database, allowlist, reputation feed, or brand endorsement. `NO_KNOWN_WARNING_SIGNS` means these local checks found no sufficient warning combination, never that the subject is safe. The heuristics cannot inspect redirects, server contents, attachment execution behavior, or newly registered domains.

Run `./run-tests.sh` with OpenJDK 17. It uses the compiler module directly, so the `javac` launcher is not required. Tests include expected benign and adversarial cases, hash vectors and limits, and 5,000 deterministic randomized Unicode inputs for each analyzer. Main source avoids Java collection factory methods and newer String methods for Android API 26 compatibility.
